# ai-box.se

The public site for AI Box (Jakup Güven AB). Static HTML and CSS, no build step, no cookies, no analytics; fonts
self-hosted (Instrument Sans/Serif, OFL). Hosted from `main` on GitHub Pages; pushing `main` publishes. Nothing here is confidential: no internals, only what is said to a customer.

Preview: `python -m http.server 8000` in this folder, then http://localhost:8000. The trial section talks to
trial.ai-box.se (localhost:8100 when served from localhost).

Where the numbers on the page come from is kept outside this repo (HQ `knowledge/ai-box-site-numbers.md`).
